New repo incorporating submodules

bot/ - Our jazzy framework - sets up communications between sensors, actuators, and decision-making systems. Sources our "jazzy" repository.
sim/ - Our isaac sim framework - communicates with the jazzy virtual machine to allow us to test our real robot software in simulated environments. Sources our "pisaiah" repository
vanilla_sim/ - scenes, tests, configurations, and orchestration specific to this project
vanilla_bot/ - plugins and middleware for the jazzy framework, specific to this project
